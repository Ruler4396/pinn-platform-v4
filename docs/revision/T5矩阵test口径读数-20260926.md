## 三、全篇唯一能拿显著性的那组：跑完了，结果是**空**（必做5 的单一裁决）

`--paired t5c04,t5c08 / rel_l2_speed / test / mean_of_cases`：

- 配对单位 **n=11**（单位 = (obs_seed, train_seed)；**孤儿 A=0 B=0** ⇒ 两臂点位一一对应，设计干净）
- 平均差 **−0.002071**（分层 0.029925 优于均匀 0.031996，方向与验证集一致）
- **Wilcoxon W=25.0，双侧 p=0.519531**；配对 t=−0.958，p=0.360848
- **本组最小可达双侧 p = 0.000977**（pooled 口径同结论：W=26.0 p=0.577，平均差 −0.001696）

⇒ 可写的句子：**"在 5% 档，分层与均匀在 11 对配对单位上无可测差异（Wilcoxon p=0.52）。这不是功效不足（该组最小可达 p=0.00098），是测了、没有。"**
⇒ 同批必须写进去的两条限定：① **1% 档仍是 n=5**（T6 只铺了 5% 两臂），那个正向效应拿不到显著性，只能写"5 粒配对里 4 粒同向"；② 显著性这套只覆盖 `rel_l2_speed/test/mean_of_cases` 这一支。

## 五、两个装置级缺陷（我踩出来的，都要修）

1. `analyze_sweep.py` 的 `--paired` **不是 append**：一次传三对时只有**最后一对**执行，而 `accounting` 行仍打印 `配对检验=2`（= 一对 × 两个口径），看不出漏跑两对。⇒ 改 `action="append"`，并打印"请求 N 对 / 实跑 N 对"，不一致就 `INVALID`。**在这条修好之前，任何"我传了 --paired 所以配对跑过了"的说法都不成立。**
2. **臂A 没有 test 评估件**：`grep -c eval-test-cases model/scripts/sweep_lib.sh` = **0**，而 `train_joint_upnp_pin.py` 自己有 `--eval-test-cases`（注释："非空则再写一份 test_dense 评估"）。⇒ 必做1 的臂A 目前**两个口径都进不了表**（test 没有；索引里只有验证集）。补跑代价近乎零：加那一行后重投 `--only-cells 20`，已有 `metrics.json` ⇒ 走 `[skip-train]` 只补评估（这行为在 T6 那趟实测过）。
