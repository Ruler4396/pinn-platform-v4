### 种子设计与配对单位

- **两层种子，分开**（这是我复算 `sparse_sampling.py:16,26,39,57` 与 `meta.json#sampling.seed` 后必然得到的结论）：
  - `train_seed ∈ {42..46}`：只改初始化/批序/物理点采样（`train_*_strict_sparse.py:105-108` 播 `random/np/torch`）。
  - `obs_seed ∈ {0..3}`：改**点位实现**。现有 obs CSV 全部是 seed=42 的一份实现 ⇒ 只换训练种子的"多种子"**测不到采样噪声**，而采样噪声恰是分层 vs 均匀这条结论的主方差源。
- **表 M1 的 19 格：n=5（train_seed），obs_seed 固定 = 0**。报 mean±std，满足必做2 的"≥3–5 个随机种子 + mean±std"。
- **采样策略对比（表5-5）例外**：用 **8 个配对单元 = 4 obs_seed × 2 train_seed**（T6）。配对单位 = `(obs_seed, train_seed)`，两臂共享同一 `obs_seed`（同一批点位），因此差值可解释为"策略效应"。
- **检验方法**：
  1. **Wilcoxon 符号秩（配对，双侧）** 为主。→ **功效硬限：n=5 时最小可达双侧 p = 2/2⁵ = 0.0625 > 0.05，即 5 个种子在数学上不可能显著**。所以 M1 的 19 格**只报 mean±std、不做显著性声称**；显著性只由 T6 的 n=8（最小 p = 0.0078）承担。这条限制必须写进正文，否则就是【审计】批评的那类口径越界。
  2. **配对 t 检验**并列报出（n=5 时可显著，但 5 点正态假设弱）；两检验不一致时以 Wilcoxon 为准并披露两者。
  3. 区间：给 95% bootstrap CI（percentile，B=10⁴），**bootstrap 的重抽单位 = 配对单元，不是单条观测**。
  4. **禁止**把 C-test-1 与 C-test-2 当成两个独立重复去凑 n=2：它们是 2 个独立几何对象，但 test 平均的分母只有 2，报告时写成 "n=2 geometries"，且不得参与显著性声称。
  5. scipy 目前**不在** `model/requirements.txt`（现仅 numpy/pandas/matplotlib/torch 4 项）→ T5 前置补依赖。
- **结论被推翻时的预案**（见 §9 情形 1）：预先写死两段成品文字，判决出来直接选一。

## 6. 基线三件套定义

所有基线共用：同一 obs CSV、同一 `relative_l2` 实现（`train_supervised.py:361-362`）、同一 `mean_rel_l2_*`/`pressure_drop_rel_error` 汇总（`:622-663`）、同一报告切分（全点集 / interior / 分区 r0-r1-r2 / 按 boundary_type），并在表注声明 **n（观测点数）= 63、训练步 = 多少、有/无 PDE、有/无壁面构造**。

### 6.1 单网络联合 PINN（T8）
- 结构 `14 → H,H,H → 3`（同时输出 u\*,v\*,p\*），SiLU，同一组归一化器由观测点拟合（strict 口径）。
- **参数量对齐算法（确定性，不靠手调）**：
  `P(H) = 14H+H + 2(H²+H) + 3H+3 = 2H² + 20H + 3`；目标 `P* = 70,275`（双模型 = 速度子网 14→128³→2 = 35,202 + 压力子网 14→128³→1 = 35,073）→ 解 `H* = (−20 + √(400 + 8(P*−3)))/4 = 182.98` → 取 **H = 183，P = 70,641，偏差 +0.52%**；判据 ≤1%，断言落盘。
- **预算对齐（消除【审计】C.4）**：每网络更新次数 = 280（与双模型 200+80 同），**末轮检查点、不启用早停**（与双模型同规则；现有单网络 run 用的是 2000 epoch + patience 200 + 最优轮，best_epoch=1183 —— 这是不对等的主要来源）。
- 损失：数据监督 + 连续性 + 动量残差（Stokes 形式，`train_*_strict_sparse.py` 里同一函数），权重与表4-4b 对齐。
- **它必须和下面 6.2 一起报**，否则单网络赢了也说不清是"联合训练"还是"PDE 项"的功劳。

### 6.2 纯数据 MLP（T9）
- 定义 = 与 6.1 **只差 PDE 项**（同结构 H=183×3、同预算、同末轮规则、同 strict 归一化器、同 63 点）。现有 `train_supervised.py` 的 run 保留为"历史读数"，但**不作为可比基线**（参数量 35,331、预算 4.2×、最优轮选点，三处不对等）。
- 强制披露：`rel_l2_v`。该 run 全点集 `rel_l2_v = 0.5358`（`supervised/contraction_single_mlp_geometry_sparse5_strict_20260503/evaluations/metrics_val_dense.json#summary.mean_rel_l2_v`）而 `rel_l2_speed = 0.0411` —— 图5-18 只报 speed 把这条藏住了。

### 6.3 传统降阶/插值（T10）
- **插值臂**：Gaussian RBF **直接拟合观测**：`φ(r)=exp(−r²/ε²)`，`ε = max(1.15·W\*_um, 36)/W\*_um`（与在线链路 `api/pinn_platform_api.py:891-895`、`:920-922` 同族核与同尺度规则，便于说明"为什么这不是我们已经在用的东西"）；锚点=全部观测点（63 个 < 在线链路的 48 上限，不做 K-center 次采样）；岭 `λ=2e-2`（速度）/`3.5e-2`（压力）同 `:923-924`。**明确不用**在线链路那种"先验场+残差校正"，因为那需要一份已有场当基准、属于另一种设定。
- **POD 臂**：快照 = 6 个训练工况 `field_dense.csv` 的 interior 点 (u,v,p)；按分量拼列做 SVD；模态数 m = 满足累计能量 ≥ 99% 的最小 m（**m 与累计能量占比必须落盘**，不许手挑）；系数由该工况 63 个观测点的最小二乘决定，正则 `λ=1e-8·tr(ΦᵀΦ)`。测试工况（C-val/C-test-1/C-test-2）**不进快照集** —— 否则是数据泄漏。
  - 已知风险并预先承认：收缩族准一维 ⇒ 前 2–3 阶模态就吃掉绝大部分能量，POD 很可能大幅优于 PINN（见 §9 情形 3）。这是**该报的结论而不是该躲的问题**。
- **解析臂（R3，零训练，白送）**：u=1.5/W\*·(1−(2y/W\*)²)、v=0、p(x)=∫ₓ^Lout 12/W\*³ds。本轮我已给出 9 工况读数，做成表即可。
- **与 PINN 同源的评价指标**：完全同 §6 开头；额外把弯曲族按弧段/直段分区（R3-附加的做法），因为全族平均会把弧段差异摊平。

- 所有长任务 `nohup … > segNN.log 2>&1 &`，**脚本分段**：每段自带 ≤ 100 min 的墙钟预算与提前退出。
