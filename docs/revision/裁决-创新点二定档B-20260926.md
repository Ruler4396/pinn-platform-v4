## 一、为什么不选 A

A 的句式是"增益集中在观测稀疏或几何复杂、解析式不成立的区间"。这句话**结构上就是为下一次实测留的坑**：我们已经在收缩族上被同规模纯数据网络赢过一次（稠密档 0.019436 vs 本文 0.028617）、又被解析剖面赢一次。审稿人只要问"那 5% 稀疏的收缩族谁赢"，A 就要求我们**每次都有一个好读数**。而按本项目的规矩，**不能被证伪的句子不能当贡献**。

⇒ 所以：A 里保留**事实**（"速度结构需要学习"——零训练 POD+LS 在速度场差 1–2 个数量级，`rel_l2_speed` 0.532–0.828，见 `证据-armC日志摘录-20260926.md`），但**删掉一切"因此本文在某区间更优"的推断**。

1. **创新点二 = 可审计性**：本文的贡献是把双模型分阶段流程做成**可逐位复算、可审计**的实现：同观测点 / 同特征集 / 同网络规模的三臂 + 一个解析对手同框；无滑移条件由输出构造精确满足；标准化器与全部训练只吃观测点子集（严格稀疏口径）；每条声称可回指到 `model/results/.artifacts/` 与 run 级索引的行。
2. **必须同时写的限定**（放同一段，不留脚注）：本文**不提供精度优势**。在与解析 Poiseuille 对手可比的收缩族直段上，该对手优于本文模型；本文模型相对基线的差别集中在**误差的构成**（速度/压力/压降哪一项更大）与**对观测条件的敏感性**，不是平均值更低。
3. **原来的"重建出不可闭式求解的内流速度场"这句**：改为方法学发现句 —— "本文把该流场重建问题做成可证伪的对照框架；在可解析近似的区间内解析式更优，在不可解析近似的区间（弯曲族、含 T6 转角外推）内基线不再适用，此时**我们只陈述本文误差的水平与散布，不陈述优势**"。
