**计时口径**：`T0=$(date +%s%N); FreeFem++ -nw <case>.edp; T1=$(date +%s%N); echo $(( (T1-T0)/1000000 )) ms`
—— 与论文 4.2 的旧计时（`/usr/bin/time` 或 Python `perf_counter` 包裹训练）**不同口径**：这里是**单次求解的进程墙钟**，含进程启动与 I/O，不含训练；引用时必须写这句。
（上一轮 9/25 曾因 `ns/1e6` 当成秒而虚报了 497 s ⇒ 本表**只填 ms 再由本文换算 s**，换算写在进行列脚注。）

## 2. 填表命令（每档一次，冒烟先行）

```bash
D=<workspace>/model/cases/contraction_2d/cfd
for R in 1 10 50; do                      # 先单独跑 R=1 冒烟，绿了再铺 10/50
  ( cd "$D/C-base_ns_re$R" \
    && T0=$(date +%s%N) && FreeFem++ -nw C-base_ns_re$R.edp > run.log 2>&1 \
    && T1=$(date +%s%N) && echo "Re=$R wall_ms=$(( (T1-T0)/1000000 ))" )
  grep -c "NS NOT CONVERGED" "$D/C-base_ns_re$R/run.log"   # >0 就必须按降级写，不许删档
  python3 ../../../../model/scripts/finalize_ns_truth.py --level $R
done
python3 model/scripts/check_ns_re_to_stokes.py            # 承重闸：读表 + 判 PASS/FAIL
python3 model/scripts/check_ns_re_to_stokes.py --selfcheck  # 必过：0.1%→PASS、5%→FAIL
python3 model/scripts/finalize_ns_truth.py --selfcheck      # 打印地板断言 + 必红正对照
```
每格挂三件同源凭据：**同一 .edp、同一网格、同一写出侧**（派单第 4 节）。若发现对流项之外的第二处差异，本单直接回炉——`gen_ns_re_edp.py --list-differences` 就是给这一条用的（它逐行打印插入与两处声明的替换）。

## 3. 事前登记的判定（不许事后改）

| 情形 | 判决 | 表里怎么写 |
|---|---|---|
| 某档 `.edp` 打出 `NS NOT CONVERGED`（撞上 60 步上限） | **FAIL**（该档） | 保留该行，填迭代数与末次 du2；正文降档为"有限 Re 到 <该档>" |
| Re=1e-3 对 Stokes 的 rel > 2% | **整单 FAIL** | 第 1、2 件产物保留但**不进正文**；正文只写局限性 |
| 文件缺失 / FreeFEM 恢复失败 / 编译不过（含 `floor` 不认） | **INDETERMINATE** | 写"未测 + 缺哪一件"，**不得**记成通过或失败 |
| Re=1/10/50 对 Stokes 有差 | 不判 | 那列只填"物理修正量大小"，不当误差读 |

## 4. 本表已知的两处代价（先承认，别让它变成事后发现）

1. **hi/lo 伴流使每档写出两份文件**：`*_raw.csv`（6 位，字段与 Stokes 逐字相同）+ `*_raw_pair.csv`（`hi,lo`）。合并后 `*_raw_10dig.csv` 才进比较。合并器实测地板：6339 个真实量级上相对 **1.205e-11**（限 1e-10），正对照（`lo` 少打一位）相对 **1.205e-09** ⇒ 断言会变红。
2. **`hi = floor(x*1e2)/1e2` 有一个幅度前提**：|x| < 1000。本工况 |p| 实测最大 **415.058** ✓；换工况（更大压降或更多级数）必须重跑 `finalize_ns_truth.py --selfcheck`，它会直接报"存在 ≥1000 的量级"并失败。
