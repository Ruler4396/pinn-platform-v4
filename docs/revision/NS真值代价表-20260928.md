## 2. 填表命令（探针 → 单档冒烟 → 铺档；`S` 与 `D` 一次定死，别用相对 `../..`）

```bash
W=<workspace>/pinn-platform-v4 ; S=$W/model/scripts ; D=$W/model/cases/contraction_2d/cfd

# (0) 先探针：它是入库 Stokes 文本的纯追加，一个构造一行、行前有 `// PROBE <tag>`。
#     编译类错误只有上机才知道，所以让 1.5 s 的它去定位，而不是让四档求解去猜。
( cd "$D/C-base_ns_re1" \
  && T0=$(date +%s%N) && FreeFem++ -nw probe_syntax.edp > probe.log 2>&1 ; echo "probe rc=$?" \
  && T1=$(date +%s%N) && echo "probe wall_ms=$(( (T1-T0)/1000000 ))" )
tail -3 "$D/C-base_ns_re1/probe.log"          # 期望最后一行 'PROBE OK du2=...'

# (1) 单档冒烟：只跑 Re=1，绿了再铺 1e-3/10/50
( cd "$D/C-base_ns_re1" \
  && T0=$(date +%s%N) && FreeFem++ -nw C-base_ns_re1.edp > run.log 2>&1 ; echo "rc=$?" \
  && T1=$(date +%s%N) && echo "Re=1 wall_ms=$(( (T1-T0)/1000000 ))" )
grep -c "NS NOT CONVERGED" "$D/C-base_ns_re1/run.log"
python3 "$S/finalize_ns_truth.py" --level 1 --dry-run     # 地板前提在这一格就会被验掉

# (2) 铺其余三档
for R in 1e-3 10 50; do
  ( cd "$D/C-base_ns_re$R" \
    && T0=$(date +%s%N) && FreeFem++ -nw C-base_ns_re$R.edp > run.log 2>&1 ; RC=$? \
    && T1=$(date +%s%N) && echo "Re=$R rc=$RC wall_ms=$(( (T1-T0)/1000000 ))" )
  grep -c "NS NOT CONVERGED" "$D/C-base_ns_re$R/run.log"   # >0 就按降级写，不许删档
  python3 "$S/finalize_ns_truth.py" --level $R
done

# (3) 承重闸与两条自测（在仓根跑）
cd "$W" && python3 model/scripts/check_ns_re_to_stokes.py            # 逐档 PASS/FAIL
python3 model/scripts/check_ns_re_to_stokes.py --selfcheck           # 0.1%→PASS、5%→FAIL
python3 model/scripts/finalize_ns_truth.py --selfcheck               # 地板 + 三条必红对照
python3 model/scripts/selftest_ns_re.py                              # 13 条，无需 FreeFEM
```
每格挂三件同源凭据：**同一 .edp、同一网格、同一写出侧**（派单第 4 节）。若发现对流项之外的第二处差异，本单直接回炉——`gen_ns_re_edp.py --list-differences` 就是给这一条用的（它逐行打印插入与两处声明的替换）。

## 4. 本表已知的代价（先承认，别让它变成事后发现）

1. **hi/lo 伴流使每档写出两份文件**：`*_raw.csv`（6 位，字段名与 Stokes 逐字相同）+ `*_raw_pair.csv`（`hi,lo`）。合并后 `*_raw_10dig.csv` 才进比较。
2. **`hi` 的宽度是逐字段推出来的，不是选出来的**：`hi = floor(x·1eN)/1eN` 有两条不等式管着——hi 自己要在 6 位里打得出来（`N < 6 − log10(scale)`），lo 要小到合并后达到场的 1e-10（`N ≥ −log10(2·1e-10·scale) − 6`）。两条界之差恒为 ~2.3 个整数、与量级无关，所以**总有可行 N，但它随量级平移**。本工况实测：u 2.14286→N=4，v 0.0476147→N=6，p 415.058→N=2。合并器实测地板（限 1e-10，**分母用各自场的 scale**）：u **2.33e-11**、v **1.05e-11**、p **1.20e-11**。
3. **上一条是本单自己的一处纠偏，不是措辞变化**：首版只有一个 N=2 且分母用全局 scale，当时报"1.205e-11 PASS"——那是 p 的量级替 v 说话；按场分母重算，同一套写出侧给 v_star 只有 **1.05e-07**（≈7.5 位有效数字），不满足派单第 1 节第 2 件。现在三条正对照都必须红：`lo` 少打一位 → 2.33e-09；N 降一档 → 2.33e-10；退回单 N 全局宽度 → 1.05e-07。断言里**不再抄写任何宽度**：`--selfcheck` 从 .edp 文本里读 N，再与 `hi_decimals_for()` 从量级推的 N 对账，两边不一致就红。
4. **宽度前提在真产物上是被测的、不是被假设的**：`finalize --level R` 先用该档 raw 里实测的 |field| 对 `10**(6−N)` 做前提检查；超了就**拒绝合并**并印出该改成哪个 N（"re-emit this level with N=… and re-solve"）。桩求解器夹具里把 |v| 抬到 4.76 就是这样被拦下的（`selftest_ns_re.py` 控制 A）。

## 5. 本轮（9/26 晚）相对首次投递改了什么，以及为什么只有上机才知道

| 改动 | 触发事实 |
|---|---|
| 去掉全部下划线标识符：`CONV_TOL`/`CONV_MAX` 改成字面量 `1.0e-16`/`60`/`it == 59`，`hi_u/hi_v/hi_p` → `uHi/vHi/pHi` | 实例编译报 `Error line number 21 … before token _`。入库 .edp 里 `_` 只出现在字符串与注释里，所以发射侧禁掉它，并由 `--check-syntax` 逐行执法（正对照：那两行 kill 掉上一版的语句必须被抓；反对照：字符串/注释里的 `_` 不许误报） |
| 注释一律整行 | `[^/ ]+ +//` 在**全部入库 .edp** 里 0 命中 ⇒ 行尾注释无先例，也进了 lint |
| 循环右括号并进最后一条语句（`… ; }`） | 纯插入式差异集合按行内容回退，裸 `}` 与入库文件重行 → 回退会删掉入库的花括号。`assert_insertions_are_unique` 抓到，改法写在该行注释里 |
| 新增锚点唯一性断言 | 插入锚 `  ;` / `for (int i = 0; i < Th.nv; ++i) {` 若在入库文件里出现两次，会静默复制整个 Picard 块，而回退证明照样绿 |
| 进循环前 `u = 0.0; v = 0.0;` | 首迭代"就是入库 Stokes 解"此前依赖 fespace 声明的初值；显式置零后这句成为文件事实而非假设（置零会被第一次求解覆盖） |
| 弃用 `pow`：`pow(u-u0,2)` → `(u-u0)*(u-u0)` | `pow` 在别的入库工况里有、在**被逐位复算过的那份** contraction Stokes 里没有；场乘场（`1.0e-10*p*qt`）有直接先例，等价且不新增未知函数 |
| 收敛报告移到 `break` 之前 | 原来"先 break 后打印" ⇒ 收敛那一档的迭代数永远不进 run.log，代价表少一列且分不清"0 次"与"没打印" |
| 探针 .edp（纯追加，一个构造一行） | `floor`、`u0 = u`、`u = 0.0`、块内 `solve` 四个构造本机构无从验证；让 1.5 s 的探针去定位，别让四档求解去猜 |
| `finalize` 合并路径两处装置缺陷（列数被当行数比；"hi 在格点"前提恒真） | 新写的 `selftest_ns_re.py` 第一次端到端跑就抓到。前者会让每个合法档位被"两个数字相等"的报文拒掉；后者原理上不可能红（6 位舍入一个 1e-N 的倍数仍是 1e-N 的倍数），已换成可在产物上量到的幅度前提 |

派单第 3 节那三类判定（不收敛=FAIL、一致性超界=FAIL、环境不可用=INDETERMINATE）**一件没动**；`RE0_REL_LIMIT=2%`、`FLOOR_LIMIT_REL=1e-10` 两个数字一件没动（后者只是把分母从全局改成逐场，是收紧）。首版四档编译失败按派单属 INDETERMINATE（环境/语法），当时记的"未测"不因本轮修复而改写。
