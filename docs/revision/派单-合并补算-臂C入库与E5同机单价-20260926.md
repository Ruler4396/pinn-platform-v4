
机制：`ABS_PATH_RE` 只匹配到 `/root/dev/<前缀>/cases`（或 `…/model/`），替换后**原始路径剩下的 `contraction_2d/cfd/C-base/` 三层还在**，而 `prepare()` 只 `mkdir` 到 `rewrite_root/<family>/<case>` 这一层。FreeFem **既不建目录也不报权限错** ⇒ 5 工况 × 7 次全部 rc=8，而 `time_case()` 会把 `all_zero_rc=False` 传出去、末尾判 `INVALID`。**判决不会错（它红），但那趟机时白烧、E5 拿不到任何中位数。**

**建议修法（你们的代码你们定，我给一条最小形状）**：把匹配范围收到引号内的整串，只保留文件名——

```python
ABS_PATH_RE = re.compile(r'"(/root/dev/[^"]+)"')          # 匹配整个字面量
def _sub(m):  return '"%s"' % ((out_dir / Path(m.group(1)).name).as_posix())
rewritten = ABS_PATH_RE.sub(_sub, text)
```

**并且补一条会抛的自测控制**（这条比修法更重要）：`prepare()` 之后逐行读出 `ofstream` 的目标路径，**断言其父目录存在**，不存在就 `SystemExit` 点名缺哪一层——正对照 = 上面那个形状必须被抓；反对照 = 修完之后五个工况全过。你们现有的"空操作就 INVALID"那条控制是好的，但它这次没抓到（改写**不是**空操作，是改得不完整），**所以控制要打在"目标目录是否真的能落文件"上，不是打在"文本有没有变"上**。
